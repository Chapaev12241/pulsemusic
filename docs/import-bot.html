Из Spotify — сведения о песнях и поиск подходящей полной записи. Яндекс — публичная запись, когда доступна, иначе такой же поиск по сведениям о треке.

Выбери нужный вариант кнопкой.

Напиши название песни и выбери исполнителя. Для подборок — /style, «хочу японское» или «опенинги из аниме». Весь каталог исполнителя: /artist Гуф. Ссылки тоже работают.

/sourcesИсточники и ограничения
/helpПримеры сообщений
/statusХод и результат загрузки
/cancelОтменить задания
/retryПовторить загрузку

Автозапуск отправляет запрос в GitHub сразу, но время старта зависит от очереди Actions. Расписание может задерживаться. Уже добавленная музыка остаётся в Pulse.
